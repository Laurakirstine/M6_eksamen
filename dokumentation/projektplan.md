# Projektplan

## Projektets formål

Formålet med projektet er at udvikle en webbaseret opgaveplanner, hvor man som bruger kan oprette opgaver, tilføje deadlines og ændre status på opgaverne efterhånden som de bliver løst. 

## Systemets opbygning

Systemet skal bestå af fire HTML sider; én hvor man kan tilføje opgaver, én hvor man kan se alle opgaver, én side hvor man kan se igangværende opgaver organiseret efter deadline dato og én side hvor man kan se afsluttede opgaver. Samtidigt indgår en menu-linje hvori man som bruger kan navigere mellem de forskellige sider. Udover HTML benyttes CSS, til layout design og JavaScript til at integrerer funktionalitet og interaktivt.

Systemet skal knyttes til en firebase-database, hvori alle opgaverne gemmes, så de kan hentes og vises dynamisk på de andre sider.

Grundlaget for at oprette opgaverne i en database, er så systemet på sigt ville kunne tilgås og bruges af flere brugere simultant. Dermed kunne en mulig udvikling være at udarbejde en konto-login funktion og have flere brugere på opgaveplanneren. 

## Styring af projektet

Projektet planlægges og styres gennem gitHub, hvor begge gruppens medlemmer kan tilgå respository´et og arbejde gennem commit og branches. Derudover bruges gitHubs ‘projects’ til opgavestyring gennem et kanban board. Opgaver der skal udføres oprettes i ‘Issues’, så de kan integreres med kanban-boardet.
